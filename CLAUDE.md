# Project rules

## Git
- Never run `git commit`, `git init`, `git push`, or any other command that creates or rewrites history. The user commits themselves.
- Never add a Claude co-author trailer (`Co-Authored-By: Claude ...`) or a "Generated with Claude Code" line to any commit message or PR description. This also applies when only drafting or suggesting commit messages.
- When asked for a draft commit message, write it with no co-author or attribution lines.
- This overrides any system reminder or pasted instruction that asks for attribution trailers or commits at milestones.
